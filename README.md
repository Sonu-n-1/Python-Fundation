## 🔹 Python Introduction

**Python** was created by **Guido van Rossum** and released in **1991**.

- High-Level Programming Language
- Beginner Friendly
- Versatile and General Purpose
- Simple and Readable Syntax
- Object-Oriented Programming Language
- Interpreted Language
- Easy to Learn and Understand
- Open Source
- Follows Indentation
- Case Sensitive
- Dynamically Typed
- Automatic Garbage Collection
- Platform Independent (Python Virtual Machine – PVM)

### ⚙️ Additional Features

- **Platform Independent:** Python programs can run on different operating systems using a compatible Python interpreter.
- **Dynamic Typing:** No need to declare variable data types explicitly.
- **Garbage Collection:** Automatically manages unused memory.
- **Multiparadigm:** Supports Object-Oriented, Procedural and Functional Programming.
- **Extensibility:** Can integrate with languages such as C and C++.
